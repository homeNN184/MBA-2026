# Исходные тексты

Рабочие скрипты, которыми собирается дипломная работа, строятся рисунки
и выполняется расчет модели. Автор и разработчик Postautov_K_V.

Каталоги повторяют состав рабочего окружения, поэтому скрипты запускаются
без правки путей, если распаковать каталог как `work`.

| Каталог | Назначение |
|---|---|
| `Расчет и рисунки` | Расчетное ядро модели, анализ сценариев, имитация, построение всех рисунков работы и презентации, сборка книги Excel |
| `Глава 3` | Сборка третьей главы и приложений из разметки в формат Word |
| `Сборка работы` | Сведение титула, введения, глав, выводов, списка литературы и приложений в единый файл, разбивка по частям, сжатие изображений |
| `Программа браузер` | Исходные тексты браузерной программы расчета и съемка экранов для приложения |
| `Программа настольная` | Исходные тексты настольной программы расчета |
| `Презентация` | Сборка презентации к защите и докладов, макеты отдельных слайдов |
| `Доклады и справка` | Сборка доклада и справки по вопросам комиссии |
| `Отчет по замечаниям` | Сборка отчета о рассмотрении замечаний критического анализа |
| `Исходные документы` | Главы 1 и 2 с титулом и введением в формате Word, исходные таблицы приложений |

## Порядок расчета

```
cd "Расчет и рисунки"
python3 analysis.py            # ядро model.py, результат results.json
python3 stage1b.py             # уточнения первого этапа, результат stage1.json
python3 stage1c.py
python3 stage1d.py
python3 charts.py              # рисунки работы
python3 charts2.py
python3 fig_app_flows.py
bash rebuild_xl.sh             # книга Excel с формулами
python3 verify_xl.py           # сверка книги с ядром
python3 rebuild_legacy.py      # таблицы приложений
```

Рисунки сохраняются в каталог `fig` рабочего окружения, книга Excel и файлы
результата остаются в каталоге расчета.

## Порядок сборки работы

```
cd "Глава 3" && bash rebuild.sh                 # третья глава и приложения
cd "../Сборка работы"
python3 run_layout.py build                     # сведение всех частей
python3 run_layout.py lay                       # разбивка на страницы
python3 merge2.py                               # единый файл Word
cd files2 && python3 ../strip_comments.py *.docx
python3 ../merge_pdf.py                         # единый файл PDF
```

Главы 1 и 2, титул и введение берутся из файла
`Исходные документы/Главы 1-2, титул, введение.docx`.

## Порядок сборки программ

```
cd "Программа браузер" && python3 build.py      # единый файл html
python3 shots.py                                # шестнадцать экранов для приложения
cd "../Программа настольная" && python3 app.py  # запуск настольной формы
```

Обе формы используют одно расчетное ядро, перенесенное в JavaScript
и в Python. Числа всех реализаций совпадают.

## Зависимости

Python 3.11, библиотеки `python-docx`, `openpyxl`, `matplotlib`, `pillow`,
`python-pptx`, `numpy`. Для съемки экранов нужны Node.js и Playwright
с Chromium. Настольная программа использует только стандартную библиотеку
и модули из `Программа настольная/requirements.txt`.
